# PJ-Arena（骗经·连环套版）

《骗经》（张应俞《杜骗新书》）改写的第一人称多幕骗局评估器。替代 `datasets_v2` 的「读一段古文判断是不是骗局」。

## 为什么换掉 v2

v2 的二分类任务**不看内容也能满分**：

| 单特征分类器 | 测试集准确率 |
|---|---|
| 文本长度 > 200 字 | 1.000 |
| 文言虚词出现次数 | 1.000 |

fraud 样本平均 921 字、safe 样本平均 39 字，标签与文体完全共线。它测的是「文言 vs 白话」，不是「对方在骗我」。

## 它测什么

玩家在第一人称下只知道三件事：**对方说了什么、手里有什么凭证、自己已经投了多少钱**。
对方真实类型（`honest` / `small_scam` / `long_con`）只在结算时揭示。

五幕固定结构：设饵 → 示信 → 小试 → 加注 → 收网。

关键设计：
1. **核验有成本、有噪声**：可信度 0.5–0.9，会漏检；`false_alarm` 表允许对好人误报。
2. **查错对象等于没查**：小额那笔永远是真的（`s3a` 恒为 0），专心验它的人照样被套。
3. **过度核验有摩擦**：对真商人每多验一次掉 4 两预期——查到底不是免费的正确。
4. **没有必胜策略**：目标不是「识破」，是决策过程质量。

## 跑

```bash
python3 arena.py            # 12 局 × 3 类型 × 5 策略，汇总
python3 arena.py --detail   # 每局明细
python3 arena.py --play pj-03-huanyin   # 交互玩一局
python3 arena.py --json > result.json   # 给 agent / 分析用
```

## 评分

| 维度 | 含义 |
|---|---|
| V | 核验率（查了几次 / 可查几次） |
| I | 核验命中率（查的是不是该查的那一项） |
| E | 承诺升级（超出最优加注步数） |
| X | 退出时机偏差 |
| C | 信号—状态混淆（对方刚施信就跳过核验） |
| A | 揭穿后是否立即调整 |

`V` 高不等于好：**`I` 低时 V 只是白花钱**。

## 现状与限制

- 12 局为人工撰写，`truth` 表是设计值，不是统计标定结果。
- 当前策略是脚本策略，用于验证机制自洽；人类与 LLM 的实测数据尚未采集。
- 幕文本为古今混合白话，尚未区分「文言阅读难度」这一混淆变量。
