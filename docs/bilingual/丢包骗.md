# 丢包骗（共 1 则）

> **现代映射**：拾遗诈骗 / 路捡分赃  
> **特征概述**：故意丢包引诱路人，再以分赃为由调包或骗取财物

---

## 1. 丢包于路行脱换

### 原文

江贤，江西临川县人。钱本稀少，每年至七月割早谷之后，往福建崇安地方以绱鞋为生。积至年冬，约有银一拾馀两，收拾回家。

中途偶见一包，贤捡入手，约有银二三两，不胜喜悦。从前一人曰：“见者有分，不许独得。可藏在你箱中，待僻静处拿出来分。你捡者得二分，我见者得一分。”贤意亦肯，况银纳置彼箱，心中坦然无疑。行未数十步，忽一人忙赶到来，啼哭哀告曰：“我失银三两作一包，是措借纳官的。你客官若拾得者，愿体天心还我，阴功万代。”前见者故作怜悯之容，曰：“是此绱鞋财主拾得，要与我均分。既是你贫苦人的，我情愿不分，你可出些收赎与他，叫他把还你。”贤被此人证出，只得开箱，叫失银者将原银包自己取去。但得其一钱收赎，亦自以为幸；不知自银已被棍将伪包换去矣。至晚到乌石地方，取出收赎银还酒，将剩者欲并入大包。打开只见铜铁，其银一毫也无，只得大哭而罢。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 事件性质 | 路上意外拾得遗银，见者有份 | 事先布置的圈套：丢的包实为铜铁假银 |
| 人物关系 | 路人甲善意提议分赃，路人乙是丢银的苦主 | 路人甲、乙均为骗子同伙，配合演戏 |
| 财物处置 | 只花「一钱收赎」做了善事，真银仍在箱中 | 江贤开箱之际，真银大包被伪包调包 |
| 受害者心理 | 占了便宜（小钱换功德） | 被「见者有份+道德压力」双层诱导，主动暴露财物 |

## 类别总结：丢包骗的共性结构

| 要素 | 模式 |
|------|------|
| **诱饵设计** | 制造「意外拾遗」场景，利用路人的贪念与道德愧疚感 |
| **身份伪装** | 丢包者、提议分赃者均为同伙，分工扮演「苦主」「好心人」 |
| **调包机制** | 以假包（铜铁/石头）替换真包，受害者主动交出财物换取「分赃权」 |
| **空间隔离** | 得手后迅速离开现场，利用物理距离阻断追索 |
| **心理操控** | 「见者有份+道德压力」双层诱导，使受害者从旁观者变为共谋者 |
| **现代映射** | 街头「捡钱平分」诈骗、快递包裹调包、ATM假钞陷阱 |
