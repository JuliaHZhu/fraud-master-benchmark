# 伪交骗（共 4 则）

> **现代映射**：社交工程 / 熟人杀猪盘  
> **特征概述**：伪装亲近关系，长期布局，诱使受害者沉迷酒色或陷入官司，最终侵吞财产

## 1. 哄饮嫖害其身名

### 原文

石涓，湖广麻城人。富而多诈，负气好胜，与族兄石涧尝争买田宅致隙。涧男石孝，读书进学，人品俊秀，性敏能文，人多拟其可中。石涓尝怀妒忌，思"吾生平发财，被涧兄所压。今其子又居士列，是虎而辅翼也。"因思计暗伤涧、孝父子。

不数年，涧故。石孝居忧，无人检束。涓思孝年少不羁，或可诱以酒色。因伪相结纳，孝趋亦趋，孝诺亦诺，终日游戏相征逐，数以曲蘖为欢。或时有美妓，涓邀孝饮其邸；或有好戏妇，涓每搬戏邀孝饮，又令戏妇曲意奉承，务挑其淫荡之心。孝堕其术中而不觉，玩日月，荒废诗书。及服阕补考，竟列劣等。孝因发奋，往寺读书，涓辄拉友挟妓，载酒至寺欢饮。孝见妓，不觉有喜心，故态复萌。涓又劝孝娶美妾二人，朝夕纵淫。内荒于色，外湎于酒，手沾战疯，不能楷书。道考被黜，家业凋零。石涓抚掌大笑曰："吾生平之恨泄矣，计亦遂矣！"乃呼其子而训之曰："涧兄在日，家富于我。因生孝不肖，酷好饮酒宿娼，不事诗书，致令丧却前程，身如丧家之狗。尔辈宜以为鉴，慎勿踏其覆辙。"未几，其子亦被人引诱赌嫖，所费不訾。涓因年老，无如之何，唯付之长叹而已。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 关系性质 | 石涓与石孝「伪相结纳」，孝趋亦趋，孝诺亦诺 | 石涓因与石涧有隙，蓄意报复；对石孝的「亲近」是长达数年的慢性毒药 |
| 诱惑策略 | 美妓、好戏妇「曲意奉承」，务挑其淫荡之心 | 针对性设计：石孝年少居忧、无人检束，酒色是其最易被攻破的弱点 |
| 破坏路径 | 从「补考劣等」到「道考被黜」，再到「家业凋零」 | 分阶段摧毁：先废学业，再废科举前程，最后以娶妾纵淫掏空身体与家财 |
| 隐蔽性 | 石孝「堕其术中而不觉」，以为只是朋友间的游乐 | 所有邀请都披着「社交」外衣：「拉友挟妓，载酒至寺欢饮」，使堕落看起来是「朋友义气」 |
| 收割确认 | 石涓「抚掌大笑」并训子以石孝为反面教材 | 骗子的终极满足不仅是财产/前程的毁灭，更是「吾生平之恨泄矣」的心理复仇 |
| 反噬 | 石涓训子后，「其子亦被人引诱赌嫖，所费不訾」 | 因果循环：以伪交害人者，其子亦遭同术所害；涓「无如之何，唯付之长叹」 |

## 2. 哄友犯奸谋其田

### 原文

毕和，山西人。心术狡险，阴悍暗毒，乡人无不被其害者。族弟毕松，有田一段，价值五十馀金，与和田毗连。和屡谋不遂，因诈与交好，屡席相款，旦夕游戏，即同胞不啻焉。

同乡有林远者，性刚而暴。其妻罗氏，貌美好淫，与夫反睦〔目〕。和乘机挑之，遂通往来，情甚密。假意不令松知，实欲使之知之。故遮头露尾，为松觑破。松乃怪和曰："枉自与你相知。有此美妇人，何不引我一宿，岂便夺你爱乎？"和逊谢曰："此妇极有情，若引你去，必深相怜爱。恐你往来无节，事机不密，其夫若知，有误身家不便矣。"松只疑其专宠，乃私往挑之，罗氏遂允。后来情更绸缪，每候其夫出外，非和往则松往，甚且三人同床，情如一体。

将及月馀，和密报其夫曰："松弟与我至知，今闻与令正有情，我屡谏不听。闻你欲捕之，若捕得，可轻打些。彼必叫我解交，我谕他多送你些银，以绝他后日妄为。慎勿害他性命。"林远闻言，怒气填胸。次日即托言外出，须三日后方归。松专瞰远去向，闻其出外，即往其家，搂罗氏入房调耍。林远从密处突出，打入房中，二人已解衣在床。远揪松于床下凶打，罗氏拼命拿住夫手，远不能多打。松求放曰："愿以银赎免。"远曰："要何人来保认？"松曰："叫我和兄来。"远正合意，即遣人呼和至。和曰："不行正路，以至于此。须召见你亲兄来。"松曰："勿召我兄，只你代我出银与之，后日即还。"和曰："我代议事，怎好出银？但今事急矣，我若不出银，此事无由解释。然必有实物相当方可。"松因写前毗连之田契卖之。和曰："只可少作价，多则亦为林远所得。"止作价四十两。和归，取银三十两相付。远曰："须六十两。"和曰："奸情被获，合输妇价一半。纵令正美貌，可值六十金，此已一半矣。"远再三不肯。和曰："彼田价四十两，我手中无现银，不如约一月后，再在我手接十两。"远要约批。和曰："若他人议事，须加二抽头，我已该八两矣。今为你息事，何逼我约批乎？"遂无约批，放松同归。

数日后，松备本息四十四两赎前田，和不肯退。一月后，林远向和取约银。和曰："指示你撰银三十两，二两谢我，岂为多乎？"远后对人说出和教捉奸之由，松方知为和所卖。然已堕其诡计，悔无及矣。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 关系伪装 | 毕和与毕松「诈与交好，屡席相款，旦夕游戏，即同胞不啻焉」 | 毕和的真实目标是毕松价值五十馀金的毗连田段；所有「交好」都是为最终夺田布局 |
| 诱饵设计 | 毕和与林远妻罗氏私通，「假意不令松知，实欲使之知之」 | 故意「遮头露尾」让毕松觑破，激发其嫉妒与参与欲；罗氏是全局中的工具人 |
| 捉奸脚本 | 林远「托言外出」，毕松「专瞰远去向」即往 | 林远的「外出」是毕和密报后设计的陷阱；毕松自以为在偷情，实则是按剧本走进圈套 |
| 价格操控 | 田「止作价四十两」，和「取银三十两相付」 | 毕和同时扮演「调解人」和「买方」，利用信息差双向压榨：对林远压到三十两，对毕松压到四十两 |
| 债务陷阱 | 毕松「备本息四十四两赎前田，和不肯退」 | 卖契一签，毕和即撕毁「后日即还」的口头承诺；无约批使林远的十两追索亦无凭据 |
| 信息揭露 | 林远「对人说出和教捉奸之由」，松方知被卖 | 毕和的信息控制精确到月：在毕松赎田失败、林远索银被拒后，真相才从第三方泄露 |

## 3. 累算友财倾其家

### 原文

金从宇、洪起予，俱是应天府人。相隔一十馀店，皆开大京铺，各有资本千馀金。但从宇狡猾奸险，起予温良朴实。时常贩买京货，累相会席，各有酒量，欢相劝酬。

从宇思曰："人言慈不掌兵，义不掌财。我观起予慈善好义，诚直无智。何彼铺买卖与我相并也？当以智术笼络之。"以故伪相交密，时节以物相馈送，有庆贺礼，皆相请召。起予只以金为好意，皆薄来厚往以答之。从宇曰："此人好酒，须以酒误之。"乃时时饮月福、打平和、邀庆纲，招饮殆无虚日。有芳辰佳景，邀与同游；夜月清凉，私谈竟夕。起予果中其奸，日在醉乡，不事买卖。从宇虽日伴起予游饮，彼有弟济宇在店，凡事皆能代理。起予一向闲游，店中虚无人守。有客来店者，寻之不在，多往济宇铺买。由是金铺日盛，洪铺日替，起予渐穷于用。从宇随取随与之，每一半九成，一半七八成；银又等头轻少，不索其借批，但云"须明白记帐也"。不四五年间，陆续借上六百馀两。乃使济宇往取之，起予别借二百两以还。后算过帐，尚欠四百馀两。逼其写田宅为当，方思还债取田。起予一皆从言。再过两年，本息合四百五十馀两矣。济宇力逼全收。起予求从宇稍宽。从宇曰："吾银本与舍弟相共，彼在家尝怨我不合把银借你。今我不理，任你两下何如？"此时金宅有新立当契在手，起予推延不过，只得将产业尽数写契填还之。他债主知其落寞，都来逼取。千馀金家，不两三栽，一旦罄空。皆金从宇倾陷累算之故也。

洪已破家之后，从宇全不瞅睐，虽求分文相借，一毫不与矣。从宇又用此术，再交杨店之子。有识者笑杨子曰："汝是洪起予替身，何不取鉴前车乎？"杨乃渐疏绝之。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 关系性质 | 金从宇与洪起予「伪相交密」，时节馈送、庆礼相请 | 从宇的策略性评估：「慈善好义，诚直无智」= 易操控目标；所有「好意」都是掠夺的前奏 |
| 攻击向量 | 起予「好酒」，从宇「须以酒误之」 | 精准打击弱点：「饮月福、打平和、邀庆纲，招饮殆无虚日」——以社交频率淹没商业理性 |
| 不对称竞争 | 从宇「日伴起予游饮」，却有弟济宇代理店务 | 起予店中「虚无人守」，客户自然流向金铺；这是设计好的商业绞杀，而非偶然 |
| 债务操控 | 从宇「随取随与之」，银两「一半九成，一半七八成；等头轻少」 | 每次借贷都在暗中侵蚀本金质量：成色不足、重量不足，且不索借批——使债务规模模糊不清 |
| 责任转移 | 从宇说「银本与舍弟相共，今我不理，任你两下何如」 | 在收割阶段突然切断情感纽带，将债务关系「转包」给济宇；起予的「友」瞬间变为债主 |
| 收割完成 | 「千馀金家，不两三栽，一旦罄空」 | 从六百两借债到田宅尽数写契，再到本息四百五十馀两——债务复利+产业抵押+其他债主逼取，形成合围 |
| 模式复用 | 从宇「又用此术，再交杨店之子」 | 伪交骗是可复制的标准化操作：识别目标弱点→社交淹没→商业侵蚀→债务操控→产业收割 |

## 4. 激友讼奸以败家

### 原文

马自鸣，浙江绍兴人。狷巧小人，柔媚多奸。族弟马应，轻浮愚昧，家更富于自鸣。其父素与鸣父不睦，两相图而未发。自鸣见应愚呆，性又嗜酒，故时时与之会饮；亦连引诸人，共打平和。唯此两人深相结纳，人多厌之，不与共饮。二人乃对斟对酌，此唱彼和，自号为莫逆交。应有事，多取决于自鸣；鸣亦时献小计，以效忠款。应素与亲兄不睦，数扬其短，欲状告之。自鸣假意劝阻，实于当机处反言以激之，益深其怒。应遂先往告兄，经官断明，拟应欧兄之罪；又投分上解释。此为破家之始。又屡屡唆其与人争讼，家日破败。

后自鸣往小户人家取债，见其妇幼美，归家向应前夸曰："我今往某家取债，其媳妇生甚美貌，女流中西施也。我以目挑之，俯首而过。其屋只一楹，数往来于前。我神魂飘荡，不能自禁。又以笑语挑之，此妇亦笑脸回答，似亦可图。只怕其夫姑有碍，未敢施为。至今挂恋在心，寤寐思服。"应曰："此家是我甲首，又系佃户，图亦何难？我必先取之。"自鸣激之曰："汝若能得，我输你一大东道。依我说，勿去惹此愚夫，若捉住，彼粗拳，真打死也。"应曰："未闻佃客敢殴主人者。"次日，即往其家收条编。一见其妇，即挑之，遣其婆出外曰："可外出觅菜来作午。"婆方出，即强抱其妇入房。妇在从否之间，见隔壁一妇窥见躲开。妇指之曰："某姆在隔壁窥见，你勿为此。"哪肯休，只以为推托也。相缠已久，婆在外归。妇只得叫妈妈曰："主人如此野意。"婆作色叱。怒，先往县呈其拖欠条编，反允殴里长。其佃人以强奸诉官拘审，邻妇窥见，亲姑捉获。其妇又貌美倾城，满堂聚观，啧啧叹赏。因审作强奸，应拟死罪。后投分上，改作戏奸未就。而家业尽倾，田宅皆卖与自鸣。（自鸣）反责曰："我当初叫你勿为，你不听吾言，以至于此。"应曰："你口虽叫我勿为，先已造桥，送我在桥中去矣，难回步也。今欲怪你，不得。孟子谓'非之无可举，刺之无可刺'，正你这样人也。"

田卖尽，自鸣绝不与往来。朝夕相借，惟干谒亲兄，方知亲者终是亲；彼酒肉朋友，真伪情也。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 关系伪装 | 马自鸣与马应「自号为莫逆交」，应「有事多取决于自鸣」 | 自鸣因父辈不睦而怀恨，对应的一切「忠款」都是陷阱；应的「嗜酒、愚呆」使其成为完美傀儡 |
| 诉讼诱导 | 自鸣「假意劝阻」应告兄，「实于当机处反言以激之」 | 这是自鸣的标志性手法：表面劝阻，实则以反向激励加深对方的执念；「破家之始」由此奠定 |
| 色诱布局 | 自鸣夸佃户媳妇美貌，「神魂飘荡，不能自禁」 | 自鸣主动识别目标，然后以「炫耀猎物」的方式激发应的占有欲和竞争心；「我先取之」是应的自主宣言，实则是自鸣植入的 |
| 激将深化 | 自鸣说「若捉住，彼粗拳，真打死也」，应答「未闻佃客敢殴主人者」 | 第二次反向激励：以恐吓性预言激发应的等级优越感；应的逻辑完全被自鸣的框架锁定 |
| 司法陷阱 | 应「先往县呈其拖欠条编，反允殴里长」，佃人反以强奸诉 | 应先呈状是致命失误：在强奸尚未发生时就主动制造诉讼记录，使后续「强奸」被坐实为主动挑衅 |
| 收割完成 | 「家业尽倾，田宅皆卖与自鸣」 | 自鸣是应的莫逆交、诉讼顾问、色诱诱导者，最终成为其田宅的买家——全链条闭环 |
| 责任推卸 | 自鸣反责「我当初叫你勿为」，应回应「先已造桥，送我在桥中去矣」 | 应的醒悟来得太迟，但认知清晰：自鸣的劝阻是桥梁的一部分，「非之无可举，刺之无可刺」——所有环节都是合法的，合起来却是谋杀 |

## 类别总结：伪交骗的共性结构

| 要素 | 模式 |
|------|------|
| **目标筛选** | 选择有财富/有前程但性格有弱点（好酒、愚呆、慈善、轻浮）的熟人 |
| **长期潜伏** | 以「伪相交密」建立信任，时间跨度从数月到数年不等 |
| **弱点精准打击** | 酒、色、赌、讼——针对目标最脆弱的维度持续诱导 |
| **反向激励** | 表面劝阻，实则以激将法、竞争心诱导对方主动跳入陷阱 |
| **多角色扮演** | 同一人同时扮演好友、调解人、债权人、买家，全链条收割 |
| **责任切割** | 所有关键环节都是受害者「自愿」的，骗子仅提供「建议」或「陪伴」 |
| **现代映射** | 熟人杀猪盘、PUA情感操控、职场捧杀、投资群托 |
