# 强抢骗（共 4 则）

> **现代映射**：暴力抢夺 / 路霸  
> **特征概述**：公开使用暴力或威胁抢夺财物

---

## 1. 私打印记占铺陈

### 原文

乡有尤刁民者，侮法健讼，渔猎下民。人闻其刁风，莫不畏而远之。一日，往府搭船，已先入船坐。后搭船者群至，萍水相逢，彼此各不相识，船中对坐漫谈。忽讲及按院拿刁民事。内有姓丘后生，不知尤刁民之在船也，与众曰："闻此时本县唯尤五最刁，凡与人暂处，无不被其骗害者。若得按院除了此人，民亦安生。"尤五心中冷笑，谓"吾与尔何干，既扬我刁，又愿按院除我？此人若不白骗他一场，枉得此刁名也。"见丘生所带铺陈甚好，即取一木印，挨近其毡条白处，私打一印号于中。

船晚至岸，各收拾自己行李而去。尤刁民尾丘生之后，行至府前，在仆担头把铺陈抢下，曰："多劳你挑，我自拖去。"丘生来抢，曰："是我铺陈，你拖何去？"二人互争不开，打入府堂上去。尤曰："是我物，他强争。"丘亦曰："是他争我物。"太爷曰："你两人互争，各有甚记号？"丘曰："我自买来的，未作记号。"尤曰："我毡条内打有印记。"当堂开视，尤取衣带中木印对之，果相同。太府曰："此是尤某之物，丘何得冒争！"将丘打十板，令尤领铺陈去，各赶出府外。丘骂曰："你这贼是何人，敢如此骗我？后必报之！"尤五曰："适船间你说尤刁民者，即是我。我与你何干，而终日道我刁？故教训你，刁人是这等做耳！"丘心中方悔："是我妄称人恶，故致此失也。"

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 机会识别 | 尤五在船上听到丘生批评自己，「心中冷笑」 | 丘生不知尤五在船，信息完全不对称；尤五利用这种「匿名讨论」的盲区，将言语冒犯转化为掠夺借口 |
| 印记伪造 | 尤五「取一木印，挨近其毡条白处，私打一印号于中」 | 印记是当场制造的「证据」：在船上趁人不备私印，到公堂上变为「我有记号，你没有」的司法优势 |
| 暴力前置 | 尤五「在仆担头把铺陈抢下」，引发互争 | 先制造占有事实，再诉诸公权力；丘生从受害者变为「冒争者」，被太府打十板 |
| 公权力套利 | 太府以印记为唯一裁判标准，将丘打十板 | 司法程序被印记绑架：太府未追问印记来源、购买凭证，仅以「有无记号」定归属；这是制度性的信息懒惰 |
| 羞辱闭环 | 尤五揭示身份：「适船间你说尤刁民者，即是我」 | 抢劫不仅是财产掠夺，更是言语报复：尤五要让丘生明白「妄称人恶」的代价；丘生「方悔」说明羞辱目的达成 |
| 受害者心理 | 丘生从「骂尤刁民」到「被尤刁民骗」到「方悔」 | 受害者经历了完整的认知崩溃：从道德高地（批评刁民）到司法败者（被打十板）到自我归罪（悔不该说人恶） |

## 2. 膏药贴眼抢元宝

### 原文

县城有一银匠，家颇殷实，解户领秋粮银，常托其倾煎。一日倾煎元宝，心内尚有系未透处，夜间又煮洗之。其铺门有一大缝，外可窥见其内。一棍买一大膏药，夜间潜往窥之。见其把两元宝洗讫，放于炉边，棍在外作叫痛声，呼曰："开门！"银匠问曰："是谁？"棍外答曰："被赃坯打得重，求你炉边灼一膏药贴之。"银匠开门与入。棍作瘸行状，且手战呼痛，蓬头俯视，以一大膏药在炉边灼开，把两手望银匠当面一贴，即抢一元宝以逃。银匠不胜热痛，急扯下膏药，元宝已被其窃一去矣。急叫："有贼！"且出门追赶，不知从哪路去。彷徨追过数十步，只得怅恨而归。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 侦察前置 | 棍「夜间潜往窥之」，见两元宝洗讫放炉边 | 银匠铺门有大缝，内部活动完全暴露；棍的犯罪是信息优势的直接转化 |
| 身份伪装 | 棍「作叫痛声」，称「被赃坯打得重，求你炉边灼一膏药贴之」 | 伪装成弱者求助，激活银匠的同情心；「炉边灼膏药」是精准的空间引导——目标物（元宝）就在炉边 |
| 物理操控 | 膏药「灼开」后贴面，「不胜热痛，急扯下膏药」 | 利用灼热的物理疼痛制造信息盲区：银匠在剧痛中无法视物、无法反应；2-3秒的窗口足够抢走元宝 |
| 逃脱设计 | 「不知从哪路去」「彷徨追过数十步」 | 夜间+疼痛+慌乱，银匠完全丧失追踪能力；棍的逃跑路线是预先勘察过的 |
| 受害者心理 | 银匠「怅恨而归」，家颇殷实 | 殷实反而成为目标（解户常托倾煎）；银匠的善意（开门助人）被精确利用 |
| 现代映射 | 假外卖员入室抢劫、假维修工盗窃、利用信任身份的暴力犯罪 | 所有案例的核心都是：以可信身份获取进入权，再以突发暴力剥夺反应能力 |

## 3. 石灰撒眼以抢银

### 原文

孙滔，河南人也。常买绵布，在福建建宁府卖。一夜，在银匠王六店煎银，倾煎已讫，时对二包在桌。二人复在对银，有一盗径入其铺，将石灰撒其目。二人救目不暇，盗即将桌上所包之银拿走。滔拼命赶去，将及，盗乃丢一包于地。滔拾包归，到银铺开视之，则皆铁矣。后竟无迹可捕也。

语云："贼是小人，智过君子。"诚哉是言也！其始入铺，撒灰腌人之目，致人无暇顾其财；追将近身，丢包于地，乃杜赶以脱其身也。此岂贼窥伺之机熟，而慢藏诲盗？然滔之不谨于其素，有以致之矣。鉴此惩噎，是为得之。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 突袭设计 | 盗「径入其铺，将石灰撒其目」 | 无预警攻击：石灰致盲是瞬间的信息剥夺，使两个成年男子完全丧失防御能力 |
| 追踪误导 | 盗「丢一包于地」，滔「拾包归，则皆铁矣」 | 双层欺骗：第一包是真银（已被拿走），第二包是假包（铁块），专门用于延缓追捕；滔拼命追的是假目标 |
| 成本收益 | 盗只用石灰+铁块，换取一包真银 | 极低成本、极高效率；丢包是「止损设计」——用假包换逃跑时间，而非与追捕者对抗 |
| 信息黑洞 | 「后竟无迹可捕也」 | 夜间+失明+假包误导，所有追踪线索都断裂；建宁府的街市为盗提供了完美的逃逸网络 |
| 受害者心理 | 作者评「慢藏诲盗」「不谨于其素」 | 传统的受害者归罪：将犯罪归因于受害者的「不慎」；但银在银匠店中煎洗是正常商业行为，非「慢藏」 |
| 现代映射 | 喷辣椒水抢劫、闪光弹突袭、调包诈骗 | 核心逻辑一致：感官剥夺→快速夺取→假目标干扰→消失在复杂环境中 |

## 4. 大解被棍白曰抢

### 原文

王亨，南京扬州府人，是本府典吏。二考已满，该上京办事。家贫无措，措借亲朋银十馀两，独往北京，为办事使用。始到京中，在教军场边草坪中大解。方脱下裤，陡被二棍拿住，且骂且剥曰："你这贼偷我衣物来。"即把其衣服并银一时抢去逃走。待他起来，缚裤赶之，二棍逃已远矣。亨行路日久，力已疲倦，拼死赶他不上，懊恨冲天，只得在会同馆乞借盘缠回家，另作区处。

### 信息面对称分析

| 维度 | 纸面说法 | 实际情形 |
|------|---------|---------|
| 时机选择 | 王亨「方脱下裤」时被抢 | 生理需求的脆弱窗口：大解时裤子脱下一半，行动不便，完全无法反抗或追逐 |
| 合法性伪装 | 二棍「且骂且剥曰：你这贼偷我衣物来」 | 给抢劫披上「追赃」外衣：旁观者是棍的潜在同盟，不会帮助「小偷」；王亨即使呼救，也会被误解 |
| 速度优势 | 「待他起来，缚裤赶之，二棍逃已远矣」 | 2-3秒的着装时间差足够逃脱；王亨「行路日久，力已疲倦」，生理状态处于低谷 |
| 空间选择 | 教军场边草坪，公开场合 |  paradoxically，公开场所有更多目击者，但棍利用的是「 Witnesses are less likely to intervene in what looks like a legitimate apprehension」 |
| 后果摧毁 | 王亨「只得在会同馆乞借盘缠回家」 | 不仅是财产损失（十馀两），更是人生计划的彻底摧毁：二考已满、上京办事、未来仕途，全部归零 |
| 受害者心理 | 「懊恨冲天」 | 双重羞耻：被抢的屈辱+向人乞讨的屈辱；典吏本应体面，此刻沦为乞丐 |

## 类别总结：强抢骗的共性结构

| 要素 | 模式 |
|------|------|
| **时机精准** | 选择受害者最脆弱的时刻：上厕所、夜间独行、铺陈暴露、煎银专注 |
| **感官剥夺** | 膏药贴眼、石灰撒目、暴力突袭——剥夺视觉或行动能力以消除反抗 |
| **合法性伪装** | 诬为小偷、伪造印记、假扮求助者——给暴力抢劫披上正当外衣 |
| **信息制造** | 私打印记、丢假包、制造「追赃」 narrative——创造有利于己的「证据」 |
| **低对抗设计** | 避免正面冲突，利用疼痛、混乱、假目标争取逃跑时间 |
| **公权力套利** | 利用司法程序的懒惰（以印记定归属）或社会偏见（不帮「小偷」） |
| **现代映射** | 飞车抢夺、街头喷迷药、假警察搜身、碰瓷后趁乱盗窃 |
