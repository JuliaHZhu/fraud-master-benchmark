## Pattern Summary: Common Structures in Fake-Credential Scam

| Element | Pattern |
|---------|---------|
| **Authority Parasitism** | Borrow real or fabricated authority identities: academic examiners, nobles, local officials, or seasonal power-brokers |
| **Ritual Packaging** | Use formal handbooks, seals, deposits, and key handovers to create ceremony that substitutes for real guarantees |
| **Spatial Control** | Control physical spaces (side doors, empty rooms, city gates, shops) to control the flow of information |
| **Collective Silence** | The illegality of buying degrees makes victims ashamed to speak out, creating an information孤岛 |
| **Insider Endorsement** | Low-level officials (clerks, scribes, runners, gatekeepers) provide "official backing" from within the system |
| **Infrastructure Investment** | Long-term setup: buying houses, marrying, opening inns to build credibility |
| **Modern Equivalent** | Degree-mill scams, fake admission letters, admissions-agent fraud, thesis-writing services |
