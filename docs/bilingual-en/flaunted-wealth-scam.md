## Pattern Summary: Common Structures in Flaunted-Wealth Scam

| Element | Pattern |
|---------|---------|
| **Incentive Manufacturing** | Victims actively display wealth (fancy clothes, large cargo), triggering criminal motives |
| **Identity Borrowing** | Scammers borrow official identities (young master, county deputy) to gain trust, or forge official endorsements |
| **Defense Dismantling** | Use "reciprocal courtesy" and "returning favors" as social rituals to诱导 victims to voluntarily lower their defenses |
| **Drug Control** | Use datura flowers (three-year茄花) and other poisons to麻痹 victims, depriving them of resistance ability |
| **Spatial Control** | Enclosed environments (passenger boats, inns) make external assistance impossible |
| **Information Delay** | The coma period after poisoning or knockout provides ample escape time |
| **Victim Psychology** | Wealth-flaunting psychology and excessive reliance on "official endorsement" |
| **Modern Equivalent** | Wealth-flaunting attracting robbery, social-media晒财引盗, drug-assisted robbery, phishing fraud |
