## Pattern Summary: Common Structures in Dropped-Bag Scam

| Element | Pattern |
|---------|---------|
| **Bait Design** | Create an "accidental find" scenario, exploiting passersby's greed and moral guilt |
| **Identity Disguise** | The bag-dropper and the split-proposer are both accomplices, playing the roles of "victim" and "good samaritan" |
| **Switch Mechanism** | Replace the real bag with a fake one (filled with copper, iron, or stones); the victim voluntarily hands over valuables to secure "splitting rights" |
| **Spatial Isolation** | Flee the scene immediately after success, using physical distance to block pursuit |
| **Psychological Manipulation** | Double-layer inducement: "finders-keepers" + moral pressure turns the victim from bystander into accomplice |
| **Modern Equivalent** | Street "found-money split" scams, package swapping, ATM fake-bill traps |
