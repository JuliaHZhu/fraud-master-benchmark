## Pattern Summary: Common Structures in Theft and Robbery

| Element | Pattern |
|---------|---------|
| **Identity Disguise** | Use "legitimate" identities like examination scholars or merchants from other prefectures to gain access to target spaces |
| **Spatial Penetration** | Use "renting rooms" or "depositing goods" as pretexts to bring robbery tools (horses, cargo containers) and personnel inside the target |
| **Collective Anesthesia** | Use banquets or datura flowers (poison) to simultaneously麻痹 all potential resisters |
| **Time Window** | Operate late at night or early morning, exploiting gaps in urban management (city gates opening, guards slacking) |
| **Professional Division** | Professional skills of mounted bandits (horse-jumping acceleration), team coordination (two men per chest) |
| **Retreat Design** | Pre-set escape routes (alleys, waterways), using speed advantages (horses, boats) |
| **Modern Equivalent** | Home invasion robbery, drug smuggling via express delivery, disguised property maintenance / repair burglary, flash-delivery robbery |

## Appendix: Ming Dynasty Slang Glossary

| Term | Meaning |
|------|---------|
| **棍 / 光棍** | Swindler, rogue (Ming street slang) |
| **伙** | Accomplice, partner in crime |
| **牙** | Broker, middleman |
| **衙役** | Government runner, bailiff |
| **棍徒** | Gang member, thug |
| **作契对银** | Formal contract and silver exchange (standard Ming transaction) |
| **打抽丰 / 秋风** | Seasonal grafting — exploiting official connections for money/gifts |
| **龟奴** | Brothel pimp, procurer |
