## Pattern Summary: Common Structures in Marriage Fraud

| Element | Pattern |
|---------|---------|
| **Identity Fabrication** | Forge widowed, titled, or widow marriage identities; or demote one's own mother to wife status |
| **Scene Staging** | Use temple rituals, inn encounters, and neighborly interactions to create "natural" meetings |
| **Emotional Hunger** | Target marriage anxiety: childlessness, widowhood, shrewish wife, advanced age—offering instant emotional/sexual gratification |
| **Progressive Control** | From marriage advice to dowry handover to estate takeover, every step is packaged as "for your own good" |
| **Violence Escalation** | Murder (pushing into the river), false accusation (forced marriage to a titled woman), manufactured conflict (cloth-shop dispute) |
| **Legal Arbitrage** | Use withdrawal of charges, reconciliation, and flight to convert criminal cases into civil disputes or unresolved cases |
| **Time Dimension** | From instant fraud (titled-woman case) to twenty-year karma (frog case), marriage fraud return cycles vary enormously |
| **Modern Equivalent** | Bride-price scams, international marriage-broker fraud, inheritance marriages, spouse murder for insurance, emotional pig-butchering |

| **伙** | Accomplice, partner in crime |

| **衙役** | Government runner, bailiff |
| **棍徒** | Gang member, thug |
