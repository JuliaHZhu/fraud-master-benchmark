## Pattern Summary: Common Structures in Deception and Intimidation

| Element | Pattern |
|---------|---------|
| **Authority Forgery** | Borrow unverifiable authority identities: academic examiners, underworld courts, government officials |
| **Information Commodification** | Package unverifiable information (dreams, fate, death predictions) as purchasable "certainty" |
| **Scene Misdirection** | Exploit information blind spots in urban/rural spaces (alleys, village offices, doorsteps) to create cognitive illusions |
| **Greed Activation** | Activate victims' self-interest calculations with high returns (silk, death avoidance, military victory), making them actively cooperate |
| **Time Window** | Exploit anxiety cycles (before exams, death fears) or service gaps (mail delivery, selection) to complete the harvest |
| **Unrecoverable Loss** | Scammers use fake identities, fake documents, and fake promises; by the time victims discover the fraud, the scammer has vanished or the information has expired |
| **Modern Equivalent** | Telecom fraud, fortune-telling scams, fake police/court/prosecutor scams, fake investment recommendations, phishing |

## Appendix: Ming Dynasty Slang Glossary

| Term | Meaning |
|------|---------|
| **棍 / 光棍** | Swindler, rogue (Ming street slang) |
| **伙** | Accomplice, partner in crime |
| **牙** | Broker, middleman |
| **衙役** | Government runner, bailiff |
| **棍徒** | Gang member, thug |
| **作契对银** | Formal contract and silver exchange (standard Ming transaction) |
| **打抽丰 / 秋风** | Seasonal grafting — exploiting official connections for money/gifts |
| **龟奴** | Brothel pimp, procurer |
