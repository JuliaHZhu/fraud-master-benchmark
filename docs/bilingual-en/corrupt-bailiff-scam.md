## Pattern Summary: Common Structures in Corrupt-Bailiff Scam

| Element | Pattern |
|---------|---------|
| **Power Arbitrage** | Exploit positional convenience to obtain non-public information (magistrate's private remarks, judge's psychology), packaging it as "inside connections" for sale |
| **Information Blockade** | Create information black holes between officials, victims, and well-meaning third parties, keeping each party ignorant of the others |
| **Reverse Exploitation** | Exploit honest officials' governance anxiety (preventing clerks from monopolizing power) as a lever to reduce liability |
| **Technical Manipulation** | Clerks manipulate judicial documents (confessions, legal codes), using "intentionally severe sentencing" to force judges to reduce sentences |
| **Layered Harvesting** | First collect a large sum for "connections," then勒索 again under names like "case closure fee" and "thank-you gift" |
| **Collusion Theater** | Clerks and criminals conspire beforehand, staging "scolding and blame-sharing" drama in court to manipulate trial outcomes |
| **Modern Equivalent** | Judicial brokers, prison "touts," jailer extortion, lawyer-client collusion to manipulate trials |
