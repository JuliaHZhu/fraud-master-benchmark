## Pattern Summary: Common Structures in Alchemy-Pill Scam

| Element | Pattern |
|---------|---------|
| **Technical Myth** | Package simple chemical tricks or physical sleight-of-hand as "immortal arts" or "turning iron into gold" |
| **Small-Scale Demo** | First use ten taels of silver to produce thirty, building trust before诱导 a large investment of one hundred taels |
| **Spatial Isolation** | Deep pits and sealed rooms both prevent inspection and provide escape routes |
| **Time Fatigue** | Forty-nine days, thirty days—long cycles exploit the psychology that "defenders inevitably slacken" |
| **Illusion Control** | Sleight-of-hand (twisting silver in palm, producing silver from sleeve) combined with psychological操控: if you ask nicely you see it, if you demand forcefully it never appears |
| **Robber vs. Robber** | When both parties are fraudsters, they use poisoning or violence as extreme means to break the deadlock |
| **Modern Equivalent** | Fake investment projects (P2P, virtual currency), pyramid schemes, perpetual-motion / water-to-oil pseudoscience scams |

## Appendix: Ming Dynasty Slang Glossary

| Term | Meaning |
|------|---------|
| **棍 / 光棍** | Swindler, rogue (Ming street slang) |
| **伙** | Accomplice, partner in crime |
| **牙** | Broker, middleman |
| **衙役** | Government runner, bailiff |
| **棍徒** | Gang member, thug |
| **作契对银** | Formal contract and silver exchange (standard Ming transaction) |
| **打抽丰 / 秋风** | Seasonal grafting — exploiting official connections for money/gifts |
| **龟奴** | Brothel pimp, procurer |
