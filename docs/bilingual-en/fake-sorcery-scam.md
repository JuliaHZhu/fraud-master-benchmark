## Pattern Summary: Common Structures in Fake-Sorcery Scam

| Element | Pattern |
|---------|---------|
| **Mystery Packaging** | Package ordinary fraud with supernatural narratives: talismans, spirit possession, fox hearts, illusion arts |
| **Trust Building** | Create a "sense of destiny" through psychological hints like "dream omens fulfilled" and "vision projection" |
| **Collusion Mechanism** | Multiple monks/Taoists分工: one creates dreams, one performs spirit descent, one伪造 auspicious signs, forming cross-verification |
| **Violence Conversion** | Use "magic control" as cover for violent acts: knife murder, gang rape, kidnapping by enchantment |
| **Legal Arbitrage** | Exploit loopholes like "no direct evidence" and "entered prison empty-handed" to bribe the entire judicial chain with silver |
| **Information Black Hole** | Victims (children, women) are physically isolated, information cannot leak; outsiders who investigate "never find any trace" |
| **Modern Equivalent** | Cult fraud, qigong scams, spiritual retreat courses, hypnotic control, "miracle" scripts in telecom fraud |
